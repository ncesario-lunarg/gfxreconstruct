## Universal block framing definition

A "frame" is delimited by a <a href="#complex-type-BlockHeader">BlockHeader</a>.

Whether or not the "frame" is compressed is determined by `(type & 0x80000000) != 0`.

i.e., compression is indicated by the MSB of the 'type' field. The actual compression algorithm (e.g. LZ4, Zstd) is a file-level option specified in the file header, not in each block header.

## Special Field Kinds

| Kind | Definition |
| --- | --- |
| <a id="special-compressible_bytes"></a>`compressible_bytes` | A byte buffer that is read differently depending on the block's $compressed flag. CONVENTION: The on-disk source for compressed data is always the entire remainder of the block's payload. Therefore, a field of this kind MUST be the last field defined in any payload and may only appear once. |
| <a id="special-slice_bytes"></a>`slice_bytes` | A view/slice into another field that is a raw byte array. |
